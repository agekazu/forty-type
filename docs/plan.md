# 開発計画

1. プロジェクト土台、CI、Cloudflare設定を整える。
2. Cornix LPの物理レイアウトとアプリ内部のキーマップ型を定義する。
3. `.vil`パーサーと検証・エラー表示を実装する。
4. キーマップから文字ごとの押下手順を解決する。
5. SVGキーボードと押下位置のハイライトを実装する。
6. 練習セッション、スコア、精度、速度を実装する。
7. Playwrightで主要フローを検証し、Cloudflareプレビューで確認する。

各項目はGitHub Issueとして管理し、`codex/<issue番号>-<短い説明>`ブランチと小さなPRに分割する。
