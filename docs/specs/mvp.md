# MVP仕様

## 目的

Cornix LP利用者が、Vialで設定した記号・数字・レイヤー操作を視覚的に練習できるようにする。

## 利用フロー

1. 利用者がCornix LP用の`.vil`ファイルを選択する。
2. アプリがブラウザ内で形式を検証し、キーマップとして読み込む。
3. 練習文字列を選ぶと、次に必要なキー、Shift、レイヤーキーがキーボード図で強調される。
4. 利用者が物理キーボードで入力し、正誤・速度・精度・経過時間を確認する。

## 受け入れ条件

- `.vil`の読み込み成功・失敗を利用者に明示する。
- 対応するASCII英数字・記号について、必要な押下位置を表示する。
- Shiftとレイヤーキーを含めて表示する。
- キーマップの内容をネットワークへ送信しない。
- PC幅から閲覧でき、キーボード図が読める。

## 対象外

アカウント、ランキング、サーバー保存、WebHID、マクロ、コンボ、タップダンス、任意のVialキーボード対応はMVPに含めない。
